# Insight Places Database

Este repositório contém o script SQL para criar o banco de dados **Insight Places**.

## Estrutura das tabelas
- **proprietarios**: informações dos donos das hospedagens  
- **clientes**: dados dos clientes  
- **enderecos**: endereços das hospedagens  
- **hospedagens**: tipos de hospedagem e vínculo com proprietários  
- **alugueis**: registros de aluguel, datas e valores  
- **avaliacoes**: notas e comentários dos clientes  

## Como usar
1. Abra o MySQL Workbench ou VS Code com SQLTools.  
2. Rode o script `insight_places.sql`.  
3. O banco será criado com todas as tabelas e relacionamentos.
